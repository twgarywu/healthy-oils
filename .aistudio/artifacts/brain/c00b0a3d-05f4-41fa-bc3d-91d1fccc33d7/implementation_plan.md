# 健康好油百科：亞麻仁油與苦茶油 (Healthy Oils Encyclopedia)

打造一個以「天然純淨、現代簡約、醫學與營養專業公信力」為核心的植物健康油權威百科網站，透過系統化生化營養圖解、烹飪發煙點互動矩陣、雙星主角深度聚焦（亞麻仁油與苦茶油）、專家選油五大心法，以及同儕審查科研情報專區，為現代家庭與健康追求者提供一站式科學食用油指南。

### User Review & Critical Decisions

> [!IMPORTANT]
> 根據第一階段需求確認，本計畫已採納以下三項關鍵決策，並確定其架構：

- **已確認決策 1（核心互動工具）**：整合「智慧烹飪配油速配器（Cooking Oil Matcher）」與「發煙點互動溫控過濾矩陣」，使用者可依照烹調手法（涼拌生飲、水炒燉煮、高溫煎炒、高溫油炸）與健康目標立即篩選最適油品。
- **已確認決策 2（視覺美學風格）**：採用「優雅植萃草本美學（Elegant Botanical Wellness）」佐「冷壓琥珀金與冷萃橄欖綠」，襯托溫潤雪花米白與典雅深灰字體，完全摒棄 AI 刻板的紫色漸層與膠囊徽章，營造頂級生活期刊與醫學權威公信力。
- **已確認決策 3（科研情報專區架構）**：採用「同儕審查科研文獻卡片（Curated Peer-Reviewed Evidence）」配合主題過濾器（心血管健康、抗發炎抗氧化、消化道修復、烹飪氧化穩定性），並提供文獻出處（NEJM, Lancet, Harvard Health, Taiwan MOHW）與臨床重點抽絲剝繭。
- **默認技術決策**：前端採用 React 19 + TypeScript + Tailwind CSS，搭配 Lucide 圖標與極速客戶端狀態篩選，所有文案內容均為純實體繁體中文專業衛教數據，嚴禁任何 Lorem Ipsum 或空泛佔位符。

### 1. Overview & Core Concept

- **目標功能**：
  1. **脂肪酸全解析**：Omega-3 (ALA/EPA/DHA)、Omega-6 (LA/AA)、Omega-9 (OA) 化學特性、促發炎與抗發炎代謝路徑對照，以及現代飲食 1:15~20 嚴重失衡現狀與 1:1~1:4 理想黃金比例調控方案。
  2. **食用油來源與發煙點圖鑑**：完整收錄 14+ 種常見食用油（亞麻仁油、苦茶油、冷壓初榨橄欖油、酪梨油、核桃油、紫蘇油、椰子油、芥花油、葵花油、大豆沙拉油、豬油、奶油等），標示飽和/單元/多元脂肪酸比例、精確發煙點（℃/℉）、熱穩定度與建議料理手法。
  3. **雙星主角深度聚焦**：
     - **亞麻仁油（Omega-3 之王）**：富含 50%~60% α-亞麻酸 (ALA)，素食者最佳抗發炎之選，人體轉化機制、不可高溫加熱（發煙點 107℃）、充氮深色避光玻璃冷藏保存與開瓶賞味期。
     - **苦茶油（東方橄欖油 / Omega-9 代表）**：油酸 (MUFA) 含量高達 80%~83%，高發煙點 (252℃) 頂級中式煎炒燉炸全能油，茶多酚、角鯊烯、芝麻素等保護胃黏膜及保護心血管的科學根據。
  4. **專家教你挑好油（五大選購心法）**：物理壓榨工法（冷壓初榨 vs 化學正己烷溶劑萃取）、容器材質規範（深色抗 UV 玻璃瓶 vs 塑膠溶出風險）、酸價指標與重金屬/黃麴毒素檢驗（SGS 檢測報告解讀）、新鮮度辨識感官法則、避光防潮保存週期。
  5. **國內外油品與健康即時情報（News & Trends）**：收錄國際指標醫學期刊（NEJM、AHA Circulation、BMJ、Lancet、Harvard T.H. Chan）與衛福部國健署最新食用油與心血管代謝研究卡片，支援分類標籤篩選與文獻詳情展開。
  6. **智慧烹飪配油速配器**：互動式滑桿與料理情境選單，即時計算安全溫度區間並推薦最佳油品。

- **目標族群**：
  - 追求抗發炎（地中海飲食、抗慢性疼痛）與保護心血管者。
  - 生酮飲食、低碳高脂、防彈咖啡實踐者。
  - 重視全家人腸胃保健、尋找耐高溫健康中式油品的家庭採買者。
  - 尋找優質植物性 Omega-3 的純素/蛋奶素食者。

- **核心價值**：
  消除大眾對油脂的迷思（「少油就等於健康」的傳統錯誤概念），以生物化學與臨床營養為基石，建立科學化、可立即付諸廚房日常實踐的好油知識庫。

### 2. User Experience & Visual Design

- **設計氛圍與色彩系統 (Botanical Wellness Palette)**：
  - **60% 基礎底色**：自然溫潤紙白與柔和暖象牙底色（Canvas: `#FAF8F5`, `#FFFFFF`, `#F3EFEA`）。
  - **30% 結構與文字面**：深墨石炭色文字（`#1F2421`, `#374151`）、高雅冷萃橄欖青（`#2D4A3E`）、淡雅鼠尾草石木灰（`#E7EBE4`）。
  - **10% 精準重點色**：冷壓初榨琥珀金（`#D97706`, `#B45309`, `#F59E0B`），應用於核心互動滑桿、關鍵指標與推薦焦點標記。
  - **無 AI 浮誇元素**：嚴格落實反 AI 規範，杜絕紫色漸層、浮誇旋轉卡片、非必要的即時連線偽燈號、厚重左側色彩飾條與藥丸形膠囊標籤。

- **字體層級排版規範 (Typographic Hierarchy)**：
  - **Display 品牌與大標題**：典雅 Serif 字體感（Playfair Display 風格氣質搭配標準繁體字重），具備長久耐看之書籍雜誌出版品質。
  - **內文與衛教數據**：清晰易讀的現代無襯線系統字體（Line-height 1.7，字符寬度控制在 65–75ch），保證長篇文章閱讀舒適。
  - **數據與溫度指標**：嚴格使用等寬對齊數字（`tabular-nums`），確保發煙點溫度、脂肪酸百分比在表格中精確縱向對齊。
  - **標題折行防孤字**：全站主標題加入 `text-wrap: balance` 與合理的寬度限制，杜絕末尾單字換行。

- **頂部導航規範 (Top Bar Contract)**：
  - 單行三區塊結構（Three-Zone Contract）：
    - **Zone 1 (品牌區)**：`健康好油百科`（輔以純文字標識「Health Oil Encyclopedia」）。
    - **Zone 2 (導航區)**：5 個純文字單行導航連結（`脂肪酸解析`、`油品發煙點`、`雙星主角`、`選油五法`、`科研快訊`），滑鼠懸停顯示細緻下底線。
    - **Zone 3 (主要操作)**：`智慧配油器`（一鍵跳轉至互動選油速配工具）。

- **頁面視覺區塊節奏**：
  1. **Hero 頂級首頁橫幅**：寬幅大氣視覺、黃金比例油脂滴落意象、核心標題與「好油抗發炎」黃金比例即時摘要數據條（Omega-3/6/9 快速指引）。
  2. **模組一：脂肪酸全解析**：Omega-3/6/9 互動切換卡片、抗發炎 vs 促發炎生化代謝瀑布圖（ALA -> EPA/DHA vs LA -> AA）、失衡現況視覺化比例條。
  3. **模組二：食用油發煙點圖鑑 & 智慧配油速配器**：
     - 雙向過濾：料理方式（涼拌、溫炒、煎炸）與脂肪酸類型。
     - 發煙點安全溫度計量尺，支援關鍵字搜尋。
  4. **模組三：雙星主角深度聚焦**：
     - 亞麻仁油（King of Omega-3）：生化組成、素食價值、保存三防、生飲與涼拌食譜建議。
     - 苦茶油（東方液體黃金）：單元不飽和高達 82%、252℃ 穩定度、胃部保護機制、中式料理百搭心法。
     - 橫向雙油直觀對照表。
  5. **模組四：專家教你挑好油（五大選購心法）**：壓榨工藝（物理冷壓 vs 化學浸出）、瓶裝避光性、酸價與驗證標章（SGS、黃麴毒素）、保存訣竅、選購避坑指南。
  6. **模組五：國內外科研快訊專區**：嚴選醫學期刊卡片、論文主題篩選器、摘要彈窗與權威機構建議。
  7. **頁尾與健康免責聲明**：正規醫學營養免責宣告、知識庫版權、安心閱讀標籤。

### 3. Key Product Decisions & Trade-Offs

- **決策 1：單頁響應式沉浸架構 vs 多頁次路由**
  - *選擇方案*：具備頂部快速錨點平滑滾動（Smooth Anchor Scroll）與即時分類篩選的流暢單頁百科，附帶互動速配器與文獻彈窗。
  - *原因*：讀者能像閱讀一本精裝版生活科學專刊一樣順暢由淺入深瀏覽，同時所有關鍵工具在手機與桌機皆能秒開秒算，無需頁面重載。

- **決策 2：純靜態精算資料庫 vs 後端資料庫串接**
  - *選擇方案*：將 14+ 種食用油之完整理化參數（發煙點、脂肪酸光譜、多酚成分、料理限制）與頂級醫學期刊資料直接內建模組化 TypeScript 常量，零延遲在前端進行即時過濾、排序與動態配對。
  - *原因*：保證毫秒級互動響應，不需要等待網路請求，免除後端維護依賴，斷網亦可流暢查閱。

- **決策 3：嚴格遵守反 AI Slop 與 Zero-Pill 規範**
  - *選擇方案*：使用優雅的純文字標籤與間隔符號（如 `·` 或 `/`）呈現文獻分類、年份、發煙點數值；按鈕與篩選器使用低彩度精緻圓角區塊，不使用浮誇的藥丸膠囊徽章或發光邊框。

- **核心資料模型 (Data Types)**：
  - `FattyAcidInfo`：脂肪酸類型、代表油品、生理活性、代謝產物、每日建議。
  - `OilProfile`：油品名稱、英文名稱、發煙點（℃）、脂肪酸分佈（SFA / MUFA / PUFA）、主要優勢、適用料理法、注意事項、是否為焦點油品。
  - `ResearchArticle`：標題、發表機構/期刊、發表年份、研究類型（人體臨床/流行病學/生化分析）、核心結論、DOI/來源索引、生活應用指引。
  - `CookingMethod`：烹調情境（生飲涼拌、低溫水炒、中溫炒蒸、高溫煎炸烘烤）與對應安全溫度門檻。

- **互動狀態管理 (Client State)**：
  - `activeCookingMethod` / `healthGoal`：驅動智慧配油器計算與推薦清單。
  - `smokePointSearch` & `fattyAcidFilter`：即時過濾圖鑑中的油品。
  - `researchCategory`：切換科研情報分類。
  - `selectedResearchModal`：閱讀單篇醫學文獻詳細臨床摘要。
  - `mobileNavOpen`：手機端抽屜式流暢導航。

- **驗證與建置計畫**：
  1. 實作完整資料定義、專業衛教知識庫與 UI 模組。
  2. 確保在 Vite 8 + React 19 + Tailwind CSS 體系下無任何 TypeScript 與語法錯誤。
  3. 執行 `compile_applet` 驗證專案構建。
